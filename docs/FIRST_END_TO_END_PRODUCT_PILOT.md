# First End-to-End Product Pilot

Day 36 proves the complete ASCOS automatic-product pipeline with one closed fixture customer idea.
The Community Workshop Planner fixture is verification data only; no live customer product,
commercial pilot, or production target is selected.

## Seven exact persisted sources

`EndToEndProductPilotService` independently reloads the submitted customer request, generated PRD,
locked PRD approval, generated roadmap, locked roadmap approval, Day 34 healthy preview, and Day 35
complete runtime-acceptance artifact. The work order and current human-issued authority bind their
digests plus tenant, customer, request, opportunity, assignment, pilot, repository, isolated branch,
commit/tree, draft PR, preview, ordered journeys, and an explicit digest mapping the customer PRD
product identity to the runtime fixture product identity.

The early chain must preserve request → PRD → PRD approval → roadmap → roadmap approval identity
and digest equality. The execution chain must preserve the Day 26/27/28/30/31/32/33/34/35
orchestration, QA, Security, workspace, reviewed-code, GitHub-delivery, DevOps, preview, runtime
configuration, browser-plan, and browser-execution digests. Drift fails before provider invocation.

## Eight terminal stages

The closed provider reads only one digest-only snapshot and returns exactly these ordered receipts:

1. customer idea;
2. locked PRD;
3. approved plan;
4. governed agents;
5. reviewed code and tests;
6. open draft pull request;
7. healthy isolated preview; and
8. complete runtime acceptance.

Every receipt binds an exact source digest and terminal state. The Day 35 source must retain one
browser launch, one authenticated session and screenshot per journey, all declared journeys passed,
and zero console, network, secret, repository, preview-mutation, production, merge, release, billing,
or pilot-selection effects.

## Persistence and evidence

One canonical mode-0600 write-once artifact records all source digests, eight stage receipts, four
passing fixture journeys, the exact draft PR and preview, and empty prohibited-effect counts. Exact
retry and restart reopen the same artifact without a second provider call. Records contain no raw
customer free text, credentials, provider payload, or local path.

Exact-head CI reruns the fixture journeys in real Chromium and renders founder-safe evidence showing
eight verified stages, four passing journeys, one bound draft PR, seven sources, and zero repository
writes, PR mutations, production deployments, or Day 37 actions.

## Stop boundary

Day 36 does not modify the customer chain, product repository, draft PR, or preview; approve or merge
a PR; deploy or promote production; release; bill; spend budget; accept risk; choose a live product;
or perform Day 37 hardening and founder UAT.
